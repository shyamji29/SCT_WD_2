# SCT_WD_2
A responsive stopwatch web application built using HTML, CSS and JavaScript with start, pause, reset and lap time features.


## 📌 About the Project

This project is a simple stopwatch application that allows users
to measure time intervals easily.

I created this project using HTML, CSS and JavaScript.

The main focus of this task was to understand JavaScript events,
DOM manipulation, timers and responsive web design.

## ✨ Features

- Start the stopwatch
- Pause the stopwatch
- Reset the stopwatch
- Record lap times
- Display multiple lap times
- Responsive design
- Simple and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
